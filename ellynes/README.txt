========================================
  ELLYNES — Food Ordering Website
  School Project
========================================

HOW TO OPEN
-----------
1. Copy this whole "Ellynes-Website" folder onto your USB drive.
2. Double-click the file called  index.html
3. It opens in your web browser (Chrome, Edge, Firefox or Safari).

You do NOT need the internet. Everything runs from the one file.


WHAT THE WEBSITE DOES
---------------------
- Browse the menu and filter it (All / Mains / Sides / Drinks)
- Add food to your cart and change the quantities
- See the live total (prices are in Namibian Dollars, N$)
- Check out, choose a payment method, and get an order number
- Log in or register (demo forms)
- Switch between light mode and dark mode
  (the moon / sun button at the top-right)

Menu:
  Flame Burger .......... N$60
  Wood-Fired Pizza ...... N$80
  Grilled Chicken ....... N$30
  Golden Fries .......... N$25
  Cold Drinks ........... N$20
  (Delivery ............. N$15)


HOW IT IS BUILT
---------------
- One single HTML file.
- HTML for the structure, CSS for the design, and JavaScript
  for the cart and checkout — all inside index.html.
- No external files, so it works completely offline.


IMPORTANT NOTE
--------------
Login, registration and payment are demonstrations for the project.
No real accounts are created and no real payment is taken.
